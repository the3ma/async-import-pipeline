# ADR-0002: The filename is the correlation ID

**Status:** accepted

## Context
The upload, the storage event and the job row have no shared session. Something must link them.

## Decision
The object key is `<task_id>.pdf`, generated by the server. The user's filename is stored only as data in the job row.

## Consequences
- No lookup table and no metadata to carry through storage.
- No collisions, and no user input in storage keys.
- Any object whose key is not a UUID is not ours and is deleted.
